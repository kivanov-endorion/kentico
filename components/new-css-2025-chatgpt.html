Container Queries

Adapt styles to the container’s own size (great for component libraries).

Mini product card

Resizes layout depending on the card's width (container query).

Cool Product
Short description that wraps nicely.
.card { container-type: inline-size; }
@container card (min-width: 360px) { .card{ padding:1.25rem; } }

:has() — relational selector

Style an ancestor based on child state (e.g., form highlighting).

Try focusing a field — the form highlights via :has().
form:has(input:focus) { outline: 3px solid color-mix(in srgb, var(--accent) 18%, transparent); }

Subgrid

Align a child grid to the parent grid columns.

Left
Sidebar
Article title
Byline and meta
Paragraph aligned to the same columns as the master grid above.
Right
Ads/Related
.parent { display:grid; grid-template-columns: 1fr 2fr 1fr; }
.child { display:grid; grid-template-columns: subgrid; }
If the browser doesn't support subgrid, the rule is ignored — the layout still works but alignment won't follow parent's columns exactly.

@property & custom property transitions

Declare a numeric custom property to enable smooth transitions of values used in transforms, filters, etc.

Hover me
Transforms interpolate because @property tells the UA the value is numeric.
@property --tilt { syntax: "<number>"; inherits: true; initial-value: 0; }
